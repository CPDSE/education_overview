Bachelor of Pharmacy – Course Overview (SDU, last updated 4 November 2026)
What do the categories mean?

Foundations

Mathematics and statistics

The concepts behind the methods: functions and rates of change, basic calculus, linear algebra, distributions, uncertainty, hypothesis testing and regression.

Examples: Linearization, a degradation rate as a derivative, AUC as an integral, a dataset as a matrix, standard errors and confidence intervals, t-tests and ANOVA.

Computing and programming

Digital literacy and the thinking behind programming, so skills carry over between languages and tools. R is the main teaching language, used to build scripts and workflows others can rerun. Also covers troubleshooting code and critical use of AI tools.

Examples: Organizing files and projects, writing and rerunning R scripts, reading error messages, finding help, using AI assistants critically when writing code.

Data workflow

Data governance

How data is organized, documented, stored and protected so it can be found, understood, trusted and reused, including the ethical and legal responsibilities of health data.

Examples: Tidy data structure, file naming, metadata and the FAIR principles, keeping raw data unchanged, secure storage, GDPR and anonymization.

Data handling

Getting data into a usable shape: importing, cleaning, handling missing values and basic transformations, done reproducibly.

Examples: Importing instrument output or spreadsheets, filtering and selecting, creating variables, converting units, joining tables, reshaping between wide and long format.

Exploration

Getting to know the data before drawing conclusions: quick summaries and plots to see patterns, catch problems and check whether the data suit the planned analysis.

Examples: Histograms, boxplots and scatter plots, summary tables by group, spotting outliers, checking assumptions such as normality or linearity.

Analysis and modelling

Extracting results from data and judging how reliable they are, from statistical analysis to mechanistic models whose parameters have real meaning.

Examples: t-tests and ANOVA, correlation, linear and nonlinear regression, confidence intervals on parameters, reaction and release kinetics, dose-response and pharmacokinetic models.

Machine learning and AI

Methods that learn patterns from data to reduce dimensions, find groups or predict outcomes, including tuning, validation and a conceptual understanding of modern AI.

Examples: PCA, k-means and hierarchical clustering, random forests, training and test sets, cross-validation and overfitting, the basic ideas behind neural networks and LLMs.

Visualization and reporting

Communicating data and results through clear, well-designed figures and transparent reports that show both the findings and how they were reached.

Examples: Choosing the right plot type, figure design, showing uncertainty, reproducible reports that combine text, code and results (e.g. Quarto), posters and presentations.
